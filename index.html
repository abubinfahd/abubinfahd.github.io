About Me

I'm an AI/ML Engineer at Technonext Software Limited in Dhaka, Bangladesh, with production experience across the full ML lifecycle — data engineering, model fine-tuning, evaluation, and deployment.

My work spans bilingual Bangla/English NLP, LLM-based generative workflows, recommendation infrastructure, and computer vision systems — deployed via FastAPI and gRPC microservices using PyTorch, Hugging Face Transformers, Kafka, and vector retrieval (FAISS, ChromaDB).

My academic foundation is an M.Sc. in Statistics from Khulna University, with a thesis track focused on deep learning for OCR. I hold an NST Fellowship from the Government of Bangladesh for academic and research excellence.

Address Parser — Bilingual Hierarchical Extraction (v3)

Production-grade hierarchical address parsing (L2–L4) for unstructured Bangla/English logistics text. Retrieval-then-rank architecture with semantic normalization. Improved L2 accuracy from 90% → 97.8%; v3 further reduced edge-case failures via tighter confidence thresholds and refined fallback strategies.

Bilingual NLPFastAPIEntity ExtractionLogistics

Hybrid Recommendation Engine — Cartup eCommerce

End-to-end recommendation system with ANN-based candidate generation, feature enrichment, Learning-to-Rank (LTR), and FP-Growth Frequently Bought Together pipelines. Near real-time updates via Kafka. Validated through A/B testing with Precision@K and NDCG optimization.

Collaborative FilteringLTRKafkaFP-GrowthPostgreSQL
Live in production · Cartup
